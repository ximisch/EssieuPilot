ESSIEUPILOT 1.6.3 RC2 — TEST DE DETECTION ATS (SANS DLL)
====================================================

CECI EST UNE PREVERSION DE VALIDATION, PAS UNE VERSION FONCTIONNELLE
CONFIRMEE POUR LES ESSIEUX DE REMORQUE.

Cette version conserve l'exécutable d'origine de la 1.6.2. Seuls
les trois libellés techniques "1.6.2" sont remplacés par "1.6.3".
Le nouveau contrôleur ATS s'exécute en parallèle sans WebView2 ni
serveur EssieuPilot local. Cela évite les erreurs des bêtas 1.7.0.

NOUVEAU DANS RC2 :
- Surveillance de amtrucks.exe toutes les secondes, sans DLL ni télémétrie.
- Une icône EssieuPilot apparaît dans la zone de notification Windows
  (près de l'horloge). Survole-la ou fais un clic droit pour consulter
  ATS LANCE / ATS NON LANCE / ETAT ATS INDISPONIBLE.
- Une notification Windows indique les changements de statut si Windows
  autorise les notifications. Un double-clic ouvre le statut.
- Ce détecteur se ferme avec le lanceur EssieuPilot.
- La version stable 1.6.2 et les profils ne sont pas modifiés.

CONTENU DE CET INSTALLATEUR :
- EssieuPilot.exe : application originale (base 1.6.2).
- EssieuPilotController.exe : module compagnon ATS clavier/manette/joystick.
- Plugins ATS\EssieuPilotATS.dll : contrôle physique EXPERIMENTAL.
- Plugins ATS\scs_telemetry_hub.dll : télémétrie locale en lecture.
- Start-EssieuPilot.ps1 : lance le compagnon et le détecteur avec l'interface.
- Watch-ATS.ps1 : diagnostic du processus ATS, sans intervention dans le jeu.

INSTALLATION :
1. Garder la version 1.6.2 installée : cette édition RC installe
   ses fichiers dans un dossier séparé.
2. Installer et lancer via le raccourci "EssieuPilot - essai ATS".
   Le raccourci lance le programme original et le contrôleur ensemble.
3. Ne pas copier les DLL dans ATS pour le premier démarrage :
   vérifier d'abord la fenêtre EssieuPilot et l'indicateur près de
   l'horloge. Lancer puis fermer ATS et observer le changement de statut.
   POUR CET ESSAI DE DETECTION, NE PAS INSTALLER LES DLL ATS.
4. Ensuite, fermer ATS, faire une sauvegarde de la partie et copier
   les deux DLL du dossier "Plugins ATS" vers le répertoire :
       American Truck Simulator\bin\win_x64\plugins
   Si une DLL portant le même nom existe, ne PAS l'écraser.
   Ne pas enlever ets2la_plugin.dll, scs-telemetry.dll ou
   scs_sdk_controller.dll. Garder Westplay retiré.
5. Lancer EssieuPilot avec le raccourci AVANT ATS 1.62, jouer SOLO DX11,
   atteler UNE remorque avec essieux directeurs.
6. Commandes initiales (selon profil): F8 marche/arrêt,
   F9 gauche, F10 droite. Consignes : 14°/s, retour 7°/s, ±35°.
   Le contrôle physique est par REMORQUE, non par essieu.
7. En cas de crash : fermer le jeu, sortir EssieuPilotATS.dll et
   scs_telemetry_hub.dll du dossier plugins ATS, puis nous envoyer
   game.log.txt et game.crash.txt.

DIAGNOSTICS :
  %LOCALAPPDATA%\EssieuPilot\diagnostics\launcher-1.6.3.log
  %LOCALAPPDATA%\EssieuPilot\diagnostics\controller-1.6.3.log

IMPORTANT :
- Le statut ATS est disponible dans la zone de notification Windows,
  PAS dans l'interface historique; une DLL n'est pas necessaire.
- L'interface originale n'a PAS de nouvel indicateur de disponibilité
  du braquage physique. Le contrôleur fonctionne en parallèle.
- Les profils sont LUS dans %APPDATA%\EssieuPilot\profiles.json,
  sans écriture automatique. Si le fichier n'est pas exploitable,
  les touches F8/F9/F10 et paramètres de base sont utilisés en mémoire.
- Il faut la DLL scs_telemetry_hub.dll, même si ETS2LA possède ses
  propres DLL ; leurs informations ne sont pas compatibles.
- Le braquage réel n'a pas encore été vérifié sur ATS 1.62 et peut
  provoquer un crash ou être inopérant.
- Ne pas utiliser en mode Convoi : compatibilité non validée.
- La version officielle 1.6.2 n'est ni supprimée ni remplacée.
- Aucun DLL n'est installé automatiquement dans ATS par ce paquet.
- Logiciel non signé ; avertissement Windows SmartScreen possible.
